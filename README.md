# BillyBoards

Expo and React Native mobile application for a billboard-campaign workflow. The app includes login and registration screens, campaign creation and details, and tabs for analytics, a map, and profile information. Supporting service code is organized under `backend/` and `backend_cloudflare/`.

## Run the mobile app

From the repository root:

```bash
npm install
npm run start
```

The package also defines `npm run android`, `npm run ios`, and `npm run web`. Configure backend endpoints and credentials for your environment before relying on service-backed features. See `app.json` and the package scripts for the app configuration.
